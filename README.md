# odin-recipes


### This project features a highly structured recipe website , containing recipes of different dishes including all the insider tips and tricks to get the exact dish that you saw in the image on the recipe page.

## Structure of each recipe : 

   #### - "Title" : name of the recipe.
   #### - "Image" : visual representation of final dish you will after         following each steps as insisted to do.
   #### - "Description" : including important facts about the dish.
   #### - "Ingredients" : featuring exact measurements , conditions and quantities of each ingredient you will require in that particular recipe.
   #### -  "Steps" : featuring exact process to achieve the exact dish which you saw in the image.
   #### - "Insider tips and tricks" : this would be only included if required in the recipe.
